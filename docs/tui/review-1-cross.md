# Review 1: cross-cutting quality (performance, motion, responsive, themes, mouse, keyboard, SSH)

**Approve with changes.** No P0. A mouse-only user and a keyboard-only user can do every task in the walkthrough. NO_COLOR did not crash. The hot path is slower than the §12 budget in five places. Tab starts animated scrolls.

## Numbers

Setup: `DemoAtlas(n=2000)` with a fixed `now`, 160×45 unless noted, Textual 8.2.8, headless Pilot. "Paint" is the end of the first `Screen._compositor_refresh` that shows the change. Keys go in through the driver (`App.on_event`), as in a terminal. Scripts and raw results: `out/review/perf/`, `out/review/walk/`, `out/review/nocolor_hunt.py`, `out/review/ssh_check.py`, shots in `out/review/shots/`.

**Note: 4 other agents ran at the same time, and they changed the code during this review.** Each number is a range over 2 or 3 runs. The absolute values can be too high. The ratios (panel shown against hidden, one class change against none) stay the same.

- **Startup:** first paint (skeleton) 316–636 ms. A bare Textual app paints in 5–12 ms. With `DetailPanel` and `SidePanel` replaced by `Static`, the first paint is 110–132 ms. The scan data is ready at 252–293 ms, the list has rows at 413–470 ms, and the first paint with rows comes at 793–864 ms. Settled at 1.0–1.8 s.
- **j/k, panel docked:** key to paint median 13–40 ms, p90 42–110 ms, max 125–255 ms. Panel hidden (`\`): 1.6–2.7 ms. At 80×24 (drawer closed): 1.5 ms. One `DetailPanel._redraw` takes 13–21 ms, once for each key.
- **Held `j` at 30 Hz:** handler lag median 0.5–3 ms, p90 13–21 ms. **pgdn:** 16–92 ms (6 ms at 80×24).
- **Search, 10 keys at 80–120 ms:** echo median 2–4 ms, max 37–88 ms. The list repaints 43–50 ms after the last key. 13–16 full rebuilds for 10 keys (12–15 ms each).
- **Toggle (`x`) to the row and the tab counts painted:** 83–93 ms median, max 173 ms. Work per toggle: `Insights()` 16–19 ms, `SkillList.rebuild` 16 ms, `views.counts` 3 times (21–23 ms), `ViewStrip._draw` 7 ms.
- **One App class change:** `App.set_class` alone costs about 40 ms (76–83 ms at times). First `m` or last unmark 70–120 ms (the next marks 18 ms), `\` 82 ms, `c` 77 ms.
- **Harness (`[` `]`):** 59–188 ms median; `views.counts` 2.5 times per switch. **View digit:** 36–42 ms.
- **Reader (`v`):** first frame 4–9 ms, file shown 49–63 ms. **See changes (`d`):** first frame 2.5–3.5 ms, files shown 50–150 ms.
- **One background reload** (`usage` or `updates`): about 150 ms of work on the event loop (SidePanel, ViewStrip, SkillList, Header, `Insights()`), from two `DataChanged` broadcasts.
- **NO_COLOR:** 0 crashes in 102 runs: 34 key and mouse paths (including `j j v`, update jobs, row flash, delete and undo, hover, right-click) at 80×24, 120×36, and 60×16. No traceback to report. Switch, mark, focus, status, and diff still read.
- **256 colors** (`COLORTERM= TERM=xterm-256color`): Rich picks 256, `theme.register` uses the snapped themes, and all 10 themes keep background, three surfaces, selection, and mark on 6 different indices.
- **Responsive:** 60×16, 80×24, 100×30, 120×36, 160×45, 240×60 follow §11: logo only below 100, drawer below 100 (52 cells at 60, 64 at 80), panel 40 at 100, `0.34 × cols` at 120, 64 at 240, key bar totals from 160, sparkline below 30 rows, reader outline at 120. 59×16 and 60×15 show only the too-small message (the key bar row was fixed during the review). Nothing overlaps.
- **Mouse only (driver clicks, 120×36 and 80×24):** all tasks done. Harness tab and `7 more ›` menu, view tab and `›` menu, search box and `✕`, row select, row switch, mark cell ×3, bulk `Turn off` and `Clear`, right-click menu → `Update`, `See changes` and `✕`, double-click → reader, outline entry, `✕`, `History`, `Move to Trash…` → `Move to Trash` → toast `Undo`, panel `✕`, Display palette dot, `? help` → click a row, divider drag (48 → 63 cells, saved), scrollbar drag, wheel per region. Tooltips exist on the switch, `⋯`, chevron, spark, status, mark cell, heat cell, divider, and `✕`.
- **Keyboard only:** 28 of 28 steps done. No focus trap. `tab` from the list takes 16–19 stops to come back.
- **SSH (`SSH_TTY` set):** animation level `basic`. Reveal is hidden in the panel, reader, action menu, and palette; `shift+r` says why. `y`: `Sent /a11y-optimize to your terminal's clipboard.` `o`: `Sent the GitHub link to your terminal's clipboard: <url>`. `limited_colors` is true only with `SSH_TTY` and no `COLORTERM` or `TEXTUAL_COLOR_SYSTEM`.
- **Motion inventory.** `full`: drawer offset 0.20 s `out_quart` / 0.15 s `in_cubic`; toast opacity 0.15 s `out_cubic` / 0.10 s `in_cubic`; switch knob one 0.06 s frame (mouse only); progress fill 0.28 s `out_quart`, fade 0.18 s `in_cubic`; spinners 80 ms; search cursor blink. `basic`: the row flash (0.7 s, 14 steps, cubic ease-out) only. `none`: nothing. No CSS `transition`. Each `scroll_*` call in our code passes `animate=False`. Wrong: Textual's focus scroll animates on `tab` at `basic` (row 5). The bulk bar fade on `m` was removed during the review. The bulk cascade (§8, optional) is not built.
